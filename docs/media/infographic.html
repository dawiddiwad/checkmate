Checkmate keeps the record

Its stages define the tests, find the gaps, drive the runs, and save the evidence. Agents and the factory read it with inbox, log, query, and export.

The oracle decides

A product-owner agent or a person answers gaps, approves plans, and accepts results.

The factory runs the agents

It runs the agents and their sandboxes, builds the code, and fixes it. Checkmate does not start agents or change code.
